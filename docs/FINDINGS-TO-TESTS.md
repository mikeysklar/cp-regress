## 5. Not covered yet

- **Signals on pins** (GPIO, UART, SPI, I2C traffic, PWM measured by another pin): peripherals_loopback is written and waits for jumpers and an I2C sensor.
- **Real displays**: display_fixture waits for a TFT and a light sensor.
- **Networking, BLE, USB HID/MIDI, sleep, audio, soak, core VM on target**: nightly fixtures are written and statically checked, not yet run on the farm.
- **Host-OS-specific USB bugs (macOS, Windows), true deep-sleep current, visual glitches**: need other rigs or a person.
- **Build / CI and docs regressions**: outside hardware testing.
